# CoCoWork 路线图

> 本目录是项目路线的**单一真源**:做过什么、在做什么、要做什么。
> 路线变更只改这里;`docs/context.md` 只记当前迭代进度,不重复记路线。

## 一句话定位

可管理、可编排、可扩展的一站式 AI Agent 平台 —— 多 Agent 编排调度 + RAG 检索 + Prompt / Skill / 知识库管理,远期支持多模态与多层权限。

## 版本鸟瞰

| 版本 | 状态 | 定位 |
|---|---|---|
| [V1](./v1.md) | ✅ 已封板(2026-06-20) | 跑通「多 Agent 编排 + RAG(向量)」核心闭环的可演示版本 |
| [V2](./v2.md) | 🚧 规划中 | 深化:多 Agent 上下文工程 · RAG 进阶 · 任务队列 · 工具生态 |
| [V3](./v3.md) | 🔭 愿景 | 多模态(语音 / 视觉)· 多层 RBAC · Skill 市场 |

## V1 一览(已封板)

平台底座 · User/认证 · Model 接入 · Knowledge/RAG(向量)· Agent(配置 + Playground + 工具)· Tool(内置)· Workspace(多 Agent 协作:对话 + 派活 + @直连 + 视角化上下文 + 多会话并发)· 前端工作台 + Admin。

详见 **[v1.md](./v1.md)**。

## 维护规则

- 一个功能"做完"才从对应版本的「规划」挪进「已实现」。
- 阅读约定:**功能清单** = 已实现、用户可用的能力(产品视角);**后端关键设计** = 底层技术亮点;前端从简。

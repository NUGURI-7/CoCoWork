# CoCoWork V2 — 规划

> 状态:规划中 · 路线总览见 [README](./README.md)
> 定位:V1 跑通核心闭环;**V2 = 做深 + 做专 + 生产化** —— 把多 Agent / RAG 从"能演示"提到"有技术含金量",顺带补上任务队列这块生产基建。

---

## P0 · 含金量主攻(简历核心,先做)

### 1. 多 Agent 上下文工程
补齐 V1 只做了 Isolate(视角化 + subagent 隔离)的另三块:
- **Compress** — 长对话历史压缩(摘要旧轮 + 留近 N 轮),可量化省 token
- **Select** — @直连成员按相关性取历史,不喂全量
- **Write** — workspace 级共享内存「白板」,成员产出互通,解决多 Agent 互相失忆
- 参考:Anthropic《多 Agent 研究系统》/《Effective context engineering》、Cognition《Don't Build Multi-Agents》、LangChain Context Engineering

### 2. RAG 进阶
从"向量检索"到"工业级检索":
- 混合检索:向量 + 全文检索(先 Postgres FTS,不够再上 ParadeDB,不上 ES)+ RRF 融合
- Rerank(先阿里)/ 多向量
- 切块优化:heading 感知切块器(命中测试已暴露双换行段对 list-heavy md 失效),A/B 对照
- 评估体系:Recall@k / MRR + LLM 自动造测试集

## P2 · 能力扩展(铺广度,按兴趣穿插)

### 4. 工具生态
- MCP 工具接入(`mcp_tools` 字段 + langchain-mcp-adapters 运行时拉远端工具)
- 有 key 内置工具的凭据层(抄 Model Provider:Fernet 加密 + 运行时装配)
- KB-as-tool v2:hybrid / keyword 模式 + 多 KB rerank + 命中测试加 mode 选择器

### 5. Workspace 增强
- 多 @ 并发应答(SSE 多路复用 + 前端按成员维护 N 个气泡)
- 沙箱产物走真文件系统(持久卷)+ 消息存引用 + 产物清单注入上下文

### 6. 管理后台补全
- admin 用户管理接真后端(list / 改角色 / 禁用 / 删)

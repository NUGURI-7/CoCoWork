## 候选方向

### 多 Agent 上下文工程(重点候选)

> 业界定位:Context Engineering 的 `Write / Select / Compress / Isolate` 四动作。V1 已做 Isolate(视角化 + subagent 隔离),V2 补其余三个。

- **Compress** — 长对话历史压缩(摘要旧轮 + 保留近 N 轮),可量化 token 降幅
- **Select** — @直连成员只取相关历史,不喂全量
- **Write / 共享内存** — workspace 级「白板」,成员产出互通,解决多 Agent 互相失忆
- 参考:Anthropic《How we built our multi-agent research system》/《Effective context engineering》、Cognition《Don't Build Multi-Agents》、LangChain Context Engineering

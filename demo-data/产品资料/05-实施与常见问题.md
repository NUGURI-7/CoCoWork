# CoCoWork 实施路径与常见问题

## 实施路径

### 第一步：选定首批业务流程

与业务部门一起梳理候选流程，优先选择满足以下条件的：

- 员工每周重复做、耗时明显
- 有明确的规则或模板，交付标准清楚
- 部门愿意用真实任务验证结果

合同初审、对外材料制作、门店营销内容这类流程通常适合作为首批。

### 第二步：整理资料与规则

- 收集流程依据：产品目录、价格与折扣规则、合同标准文本、品牌模板、话术范例等。
- 确定哪些依据放进知识库由部门维护，哪些规则需要固定在流程里。
- 明确需要员工确认的节点，例如稿件确认、补充缺失信息。

### 第三步：开发与封装

开发方把流程封装成业务模板：固定检查步骤、依据来源、交付格式和人工确认节点；需要对接的企业系统（如活动系统、工商查询）以工具方式接入，凭据由平台统一保管。

### 第四步：上线与试用

管理员在后台用业务模板创建公共 Agent，选择对话模型、绑定部门知识库并启用。先请部门内少数员工试用，用真实任务核对结果，根据反馈调整资料和规则。

### 第五步：推广与持续运营

- 在全员门户中开放，员工按业务名称直接使用。
- 部门资料维护者持续更新知识库，资料更新后立即生效，无需重新开发。
- 根据使用情况和消耗统计，调整模型选择和用量限额，规划下一批接入的流程。

## 试用期怎么验证效果

试用阶段用真实任务检验，而不是凭感觉判断：

1. **准备样本**：从近期工作中挑选一批已经由人工处理过的真实任务，例如十几份已审核过的合同、几份已经交付的客户材料。
2. **对照结果**：用 CoCoWork 处理同样的任务，与人工结果逐项对比：该发现的问题有没有发现、有没有误报、交付物能否直接使用。
3. **记录耗时**：对比员工处理同类任务前后花费的时间，区分「系统处理时间」和「员工核对修改时间」。
4. **收集反馈**：请试用员工说明哪些地方看不懂、哪一步需要人工补救，据此调整资料、规则和交付格式。

判断标准：首次使用的员工能认出可以办什么、知道要交什么、看懂拿到的结果；需要补资料或做决定时，能用自己的岗位知识判断下一步。

## 角色分工

| 角色 | 职责 |
| --- | --- |
| 业务部门负责人 | 提出需求，确认流程和交付标准，组织试用验证 |
| 资料维护者 | 上传、更新、删除本部门知识库文档，测试检索效果 |
| 管理员 | 接入模型，创建并启用公共 Agent，绑定知识库，管理用户 |
| 开发方 | 梳理流程，开发业务模板和工具，对接企业系统 |
| 普通员工 | 在门户中使用业务能力，提交材料、确认关键节点、使用交付物 |

## 常见问题

**员工需要学习 AI 相关知识吗？**
不需要。员工只需要像对同事交代工作一样描述需求，提交业务材料。模型、提示词、工具都由开发侧预先配置。

**AI 给出的结果可以直接用吗？**
CoCoWork 交付的是可供复核的结果。合同初审给出问题清单和原文位置，便于员工和法务逐条核对；文件制作交付可编辑文件，员工可以继续修改。关键节点需要员工确认后才会继续。

**资料更新后需要重新开发吗？**
不需要。产品资料、话术、规则说明等放在知识库里，资料维护者上传新版本后立即生效。只有流程本身发生变化时才需要调整业务模板。

**能否接入企业现有系统？**
可以。企业系统以工具的方式接入业务流程，例如查询活动系统、工商信息、产品库。接口凭据由平台加密保管，不暴露给员工。

**数据会不会外流？**
CoCoWork 支持私有化部署，知识库、会话和生成的文件都保存在企业自己的环境中。模型可以选择企业内部部署的开源模型，也可以选择签订数据协议的云端模型服务。

**同一个业务能力，不同门店或部门要用不同资料怎么办？**
同一个业务模板可以创建多个 Agent，各自绑定自己的知识库。例如每家门店的营销音频 Agent 绑定本店的商品资料。

**多 Agent 协作和单个 Agent 有什么区别？**
单个业务 Agent 适合一件边界清楚的工作，如合同初审。一项任务需要多种能力时，例如查资料并同时制作 PPT、Word 和 PDF，交给工作空间，由 Supervisor 拆解分派、成员分工完成。同一个业务 Agent 既可以单独使用，也可以作为工作空间的成员，流程和交付要求保持一致。

**AI 回答错了或者编造了内容怎么办？**
业务流程对依据有明确要求：合同审核只依据查到的工商信息和公司标准判断，营销音频中的优惠只采用活动系统里查到的内容，资料简报的每条信息都标注出处，查不到的会明确写「资料中没有」。员工核对时可以按出处回查原文。

**新增一个业务能力要多久？**
取决于流程复杂度和需要对接的系统。规则清楚、依据已经成文的流程开发周期较短；需要对接新系统或依据还没有整理成文的，时间主要花在梳理规则和整理资料上。

**员工的使用习惯会被记住吗？**
会。员工明确提出的长期要求，例如固定的语气、格式偏好，会被记录下来，在之后的任务中自动生效。员工也可以随时说明新的要求覆盖旧的。

**公司换了新的品牌模板怎么办？**
品牌规范集中在文档制作技能的模板里。更新模板后，之后生成的所有 PPT、Word、PDF 都会采用新规范，员工不需要做任何调整。

**能不能限制某些能力只给特定部门使用？**
目前公共 Agent 对全员可见，个人 Agent 只对创建者可见。按部门或岗位细分可见范围，是随企业实际需要继续完善的方向；知识库的访问范围同样按权限控制。

**生成的文件在哪里找？**
所有生成的文件归集在产出物面板，可以预览、下载，也可以在后续对话中引用，让 Agent 在原文件基础上继续修改。
